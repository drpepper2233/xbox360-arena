# Xbox 360 Arena — Operator Setup Guide

This document guides the operator on setting up and starting the Xbox 360 emulation arena.

## 1. Prerequisites
* **Proxmox Host:** `bigbrother` (`192.168.0.25`)
* **Dedicated GPU:** NVIDIA RTX 3090 Ti
* **Chrome Browser:** Installed on the client access machine
* **Xbox 360 Controller:** USB or Bluetooth (HTML5 Gamepad API compatible)

## 2. VM Target Specifications
The target virtual machine configuration on `bigbrother` is as follows:
* **VMID:** `360` (or next free ID)
* **VM Name:** `x360-arena`
* **CPU:** `host`, 16 Cores
* **RAM:** 32 GiB
* **Storage:** 256 GiB NVMe
* **Machine Type:** `pc-q35`
* **BIOS:** UEFI (`OVMF`) + efidisk on NVMe
* **vTPM:** Enabled (required for Windows 11 guest OS)
* **PCI Passthrough (`hostpci0`):** NVIDIA RTX 3090 Ti (GPU + Audio function, `x-vga=1`)

## 3. GPU Contention & Power Management
> [!IMPORTANT]
> **GPU Passthrough Contention:**
> The RTX 3090 Ti can only be allocated to one virtual machine at a time. 
> **You MUST shut down VM 100 (`ai-video-lab`) before powering on VM 360 (`x360-arena`).**
> Failing to do so will result in Proxmox being unable to boot VM 360 due to resource contention.

## 7. Troubleshooting
### Emulation Lag / Shader Stuttering
* **Cause:** The Xeon 8173M CPU has a base clock speed of 2.0 GHz. Emulation of the Xenon PowerPC CPU is highly bound to single-thread JIT performance, which causes stutters during shader compilation.
* **Workaround:** Allow the emulator to run the game for a few minutes to cache shaders. Performance will stabilize once critical shaders are cached on the local NVMe drive.

### Controller Not Responding in Chrome
* **Cause:** Chrome did not capture gamepad input, or the HTML5 Gamepad API is waiting for a button press.
* **Workaround:** Press any button on the gamepad after focusing the Chrome tab. Check `chrome://gamepad-internals` to verify Chrome recognizes the controller.

### VM Fails to Boot / GPU Error
* **Cause:** VM 100 (`ai-video-lab`) is still running, or the host PCI bus has hung.
* **Workaround:** Ensure VM 100 is fully shut down. If the GPU remains locked, reset the host PCIe device or reboot `bigbrother`.
